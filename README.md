# 🌙 dal-calendar

**나만의 데스크톱 일정관리 프로그램**

`dal-calendar`는 Electron과 React를 기반으로 개발한 개인용 데스크톱 캘린더 애플리케이션입니다.

월별 달력을 통해 일정을 확인하고 관리할 수 있으며, 일정별 색상 지정, 메모 작성, 완료 상태 관리 등의 기능을 제공합니다.

Windows 데스크톱 환경에서 사용할 수 있도록 제작했으며, SQLite 데이터베이스를 이용해 일정을 로컬에 저장합니다.
-> MAC환경의 경우 소스코드를 내려받아 직접 일렉트론을 이용해 빌드해야 합니다.

---

## ✨ 주요 기능

### 📅 달력 및 일정 관리
- 월별 달력으로 날짜 확인
- 일정 추가, 수정 및 삭제
- 일정의 시작 날짜와 종료 날짜 설정
- 일정별 색상 지정
- 일정 메모 작성
- 일정 완료 상태 관리

### 🔔 알림 기능
- 일정 시간에 맞춘 알림 설정
- 설정한 알림 시간에 맞춰 데스크톱 알림 표시

### 🏠 데스크톱 환경 지원
- Electron 기반의 독립 실행형 데스크톱 애플리케이션
- 창 크기 및 위치 저장
- 창 잠금 기능
- 프로그램 종료 기능

### 🇰🇷 공휴일 정보
- 공휴일 API를 활용한 공휴일 정보 표시
- API 키 설정 및 로컬 저장 기능

### 💾 데이터 저장
- SQLite 데이터베이스를 이용한 일정 관리
- 애플리케이션의 사용자 데이터 경로에 데이터베이스 저장
- 프로그램을 다시 실행해도 기존 일정 데이터 유지

## 📦 설치 및 실행

### 일반 사용자

1. GitHub 저장소의 Releases 또는 배포 페이지에서 설치 파일을 내려받습니다.
2. 설치 파일을 실행합니다.
3. 설치가 완료되면 `dal-calendar`를 실행합니다.
4. 최초 실행 시 뜨는 api키 입력 부분에 https://www.data.go.kr/data/15012690/openapi.do 해당 사이트에서 발급 받은 api키를 입력하면 공휴일 지정이 가능합니다. 

> 설치 파일의 이름과 배포 위치는 릴리스 설정에 따라 달라질 수 있습니다.

### 개발자

#### 1. 저장소 복제

```bash
git clone <저장소 주소>
cd dal-calendar
```

#### 2. 패키지 설치

```bash
npm install
```

#### 3. 개발 모드 실행

```bash
npm start
```

#### 4. 설치 파일 생성

```bash
npm run make
```

빌드 결과물은 프로젝트의 `out` 디렉터리에서 확인할 수 있습니다.

## 🗄️ 데이터 저장

`dal-calendar`는 SQLite를 사용해 일정 데이터를 로컬에 저장합니다.

데이터베이스는 Electron의 `app.getPath('userData')` 경로를 기반으로 관리됩니다.

따라서 애플리케이션을 업데이트하더라도 기존 사용자 데이터 저장 경로가 유지되고 데이터베이스가 삭제되지 않는다면 일정 데이터는 일반적으로 유지됩니다.

**주의:** 애플리케이션을 제거하거나 사용자 데이터를 직접 삭제하기 전에는 데이터베이스를 백업하는 것을 권장합니다.
